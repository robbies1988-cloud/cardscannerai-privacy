CardScannerAI privacy information

Operator: Robert Shamoon.

This is a private, single-seller card inventory and listing preparation application run on the operator's PC.

Images and listing information

The PC retains the seller's original card scans and manual inventory. Selected listing photos are sent directly from the PC to eBay Picture Services. This website does not receive or host those photographs. The local application stores image references and export records needed to prepare the seller's eBay listing files.

Account connection

eBay sign-in happens on eBay. This return page displays a short-lived, single-use authorization code for the seller to copy into the local application. The bridge does not save that code. User access and refresh tokens stay with the local application. This private Cloudflare Worker holds the operator's eBay application credentials as secrets only to verify eBay account-deletion notifications.

Deletion requests

The bridge verifies eBay's signature before retaining a minimal deletion receipt in its private database. The receipt contains an opaque notification identifier, timestamps, and one-way keyed fingerprints used to match the affected account. Raw usernames, user identifiers and EIAS tokens are discarded. The local application compares pending receipts with its authenticated seller identity, removes eBay integration data for a matching account, then acknowledges processed receipts so the bridge deletes them. Receipts for unrelated accounts do not delete the seller's records. Receipts remain queued while the PC is offline. The operator also handles any copies exported or backed up outside the application.

Service providers and access

eBay processes the seller's authorization and listing photographs. Cloudflare runs this HTTPS bridge and its private queue under the operator's account. The bridge sets no cookies, runs no analytics, and contains no advertising. The application code does not log callback URLs or notification bodies; hosting providers may process technical connection data under their own policies.
